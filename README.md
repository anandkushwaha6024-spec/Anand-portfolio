# Anand Kushwaha - Professional Full Stack Developer Portfolio

Modern, responsive, and visually impressive developer portfolio built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js), Vite, Framer Motion, and Tailwind CSS.

## 🛠️ Tech Stack

### Frontend
* **React.js** (Component-Based UI Architecture)
* **Vite** (Next-Generation Frontend Tooling)
* **Framer Motion** (Smooth entrance & scroll reveal animations)
* **Tailwind CSS** (Custom dark developer design system)
* **Axios** (API HTTP Client)
* **Lucide React** (Modern developer iconography)

### Backend
* **Node.js** (Event-driven JavaScript runtime)
* **Express.js** (Fast RESTful API Framework)
* **MongoDB & Mongoose** (NoSQL Database & ODM Schema Validation)
